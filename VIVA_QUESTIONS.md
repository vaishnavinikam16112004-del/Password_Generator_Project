# Password Generator: Viva Questions and Answers

**1. What is a password generator?**  
It is an application that creates random passwords automatically.

**2. Which programming language is used?**  
Python.

**3. What is the purpose of this project?**  
To generate random passwords based on the user's selected length and character types.

**4. Which modules are used?**  
The built-in `string` and `secrets` modules.

**5. Why is the `string` module used?**  
It provides ready-made collections of letters, digits, and punctuation characters.

**6. Why is the `secrets` module used?**  
It is designed to generate random values suitable for security-related uses.

**7. What is a function?**  
A reusable block of code that performs a particular task.

**8. What does `input()` do?**  
It accepts information typed by the user.

**9. What is a loop?**  
A loop repeats code while a condition is true or for each item in a sequence.

**10. Why is input validation needed?**  
It helps the program handle invalid lengths and incorrect responses.

**11. What is a list?**  
A list stores multiple items in one variable.

**12. What are possible future improvements?**  
A graphical interface, copy button, strength indicator, and password-manager integration.
